## Módulo Delivery, Reservas y Canales (Bloque 9)

### Integración con Apps de Delivery (PedidosYa, Rappi, etc.)
- **Configurable**: Permite la integración vía API (pedidos entran directo a cocina/KDS, sincronización de menú y stock) o el flujo manual (carga en el POS desde una tablet externa).

### Gestión de Reservas
- **Configurable**: Permite desde una agenda básica hasta gestión avanzada con mapa de salón, control de capacidad por turno y cobro de señas/depósitos para evitar no-shows.
- **Lista de espera (Walk-in)**: Gestión de fila de espera integrada al salón.

### Reparto Propio (Delivery)
- **Configurable**: Permite asignación manual de pedidos (despacho clásico) o ruteo sugerido por el sistema (basado en cercanía o carga de trabajo del repartidor).

### Seguimiento de Pedidos (Tracking)
- **Configurable**: Envío de notificaciones simples por SMS/WhatsApp ("Salió", "Entregado") o envío de un link de seguimiento en tiempo real para el cliente.

### Zonas de Reparto y Costos
- **Configurable**: Permite calcular el costo de envío mediante tarifa plana, por zonas (polígonos en mapa) o por distancia (km).

### Control de Capacidad de Delivery
- **Configurable**: Permite pausar la recepción de pedidos de forma manual (botón de pausa por tiempo definido) o automática (el sistema pausa si el KDS detecta saturación en los tiempos de cocina).

### Avisos de Pedidos para Retirar (Takeaway)
- **Configurable**: Permite aviso manual (llamada/WhatsApp por el empleado), aviso automático por SMS/WhatsApp al marcar "Listo" en el KDS, o visualización en pantallas físicas en el local.

### Web de Pedidos Propia (Dominios)
- **Configurable**: Acceso por subdominio de la app (ej. pedidos.tuapp.com/local) o conexión de dominio propio del cliente (white-label).

### Medios de Pago en Web de Pedidos
- **Configurable**: Permite cobro online por pasarela (tarjeta, QR, etc.) o pago contra entrega/retiro (efectivo, tarjeta física). El dueño habilita las opciones.

### Integración con WhatsApp
- **Configurable**: Permite usar WhatsApp solo para notificaciones (salida de pedido, ticket) o habilitar un Bot interactivo para que el cliente haga el pedido completo por chat.

### Control de Caja de Repartidores
- **Configurable**: Permite el cierre manual de pedidos en caja o el uso de una "billetera de repartidor" (el sistema descuenta el efectivo que lleva y bloquea el turno hasta que rinda cuentas).

### Comisiones de Plataformas de Delivery
- **Configurable**: Permite registrar la venta bruta (y manejar la comisión como gasto aparte) o descontar automáticamente la comisión para ver el margen neto real por canal.

### Sincronización de Disponibilidad (Stock) con Apps
- **Configurable**: Permite la sincronización automática vía API (si un producto llega a cero en el POS, se pausa en la app) o la gestión manual desde las tablets de las plataformas.

### Integración con Flotas de Terceros (Uber Flash, etc.)
- **Configurable**: Permite solicitar repartidores de flotas externas directamente desde el POS vía API (con tracking integrado) o gestionar el despacho por fuera del sistema.

### Reglas Comerciales de Delivery
- **Configurable**: Define montos mínimos de compra y distancias máximas de entrega de forma global, por sucursal o por zona.

### Carta Digital (Menú QR)
- **Configurable**: Permite usar la carta como catálogo visual simple (solo lectura, sincronizada con el POS) o habilitar la opción de autopedido y pago en mesa desde el celular.

### Generación de Códigos QR (Mesas)
- **Configurable**: Generación de QRs en formato básico (PDF para imprimir) o personalizado con branding (logo, colores, textos de bienvenida).
